# STRK20 Workbench example

This deliberately small Vite application proves that another frontend can use `@strk20-workbench/react` without importing any Workbench web internals.

From the repository root:

```bash
pnpm --filter @strk20-workbench/example dev
```

The example runs the three component states with simulated delays and fake tokens. It is an adoption example, not a real STRK20 transaction or proof.
